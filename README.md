# Tanbeehat social assets

Images hosted for social publishing via Buffer.

## Tanbeehat social videos

`tanbeehat/videos/` holds the short feature videos for the Tanbeehat social calendar (English and Arabic, 9:16 and 1:1). The scheduler loads them from their raw GitHub URLs, so keep file names stable.

## Tanbeehat brand

`tanbeehat/brand/` holds the magnet-bell logo (chosen 2026-10-30): `tanbeehat-profile-1080.png` is the profile picture for Instagram, TikTok, X, Facebook and WhatsApp Business (safe for circle crops); the `logo-rounded` (white on purple) and `logo-light` (purple on white) tiles and the bare `mark-white` / `mark-purple` come as SVG and PNG. Brand purple is `#4F008C`.

## Old pre-rebrand images

The `coco-*.png` images in the repo root are the old pre-rebrand posts and still show the previous name. Use `tanbeehat/` for all new posts.
